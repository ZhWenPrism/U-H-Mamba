# Published result tables

Machine-readable transcriptions of Tables 2–7 in the article:

- `rul_performance.csv` — point prediction across datasets and degradation phases.
- `uncertainty_quantification.csv` — interval coverage, width, calibration, and sharpness.
- `ablation.csv` — component ablations on early, middle, and late degradation.
- `cross_dataset_transfer.csv` — zero-shot and 10% fine-tuning transfer.
- `data_sensitivity.csv` — data-volume sensitivity and uncertainty response.
- `computational_efficiency.csv` — runtime, memory, parameters, and throughput.

Values are reported exactly as published in [Energies 19(2), 414](https://doi.org/10.3390/en19020414).
